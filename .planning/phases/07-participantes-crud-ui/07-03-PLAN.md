# 07-03 - Participants page CRUD integration and final verification

<objective>
Wire the participants page to the new hook and sheet layers so users can list, search, create, edit, inspect history, and inactivate participants from `/participantes` while preserving Phase 6.5 visual conventions and Better Auth protected navigation.
</objective>

<requirements_addressed>
- UI-PES-01: User can list and search participants by cached data.
- UI-PES-02: User can create/edit participants through the three-tab form.
- UI-PES-03: User can view participant event history.
- UI-PES-04: User can inactivate participants with soft-delete and preserved history.
</requirements_addressed>

<truths>
- D-01: Keep `/participantes` as the operational surface.
- D-02: Keep mobile-first card/list experience with search and filters at the top.
- D-03: "Adicionar Participante" and "Ver ficha" open the sheet workflow.
- D-04: Search responds over cached data first.
- D-06: Mutations invalidate/update participant and history query keys.
- D-10: Reads remain available to authenticated users; writes reflect existing role restrictions.
- D-11: Soft-delete is explicit and removes the participant from active list without deleting history.
- D-12: Unavailable actions are visibly permission-related.
</truths>

<threat_model>
| Threat | Severity | Mitigation |
|--------|----------|------------|
| User mistakes soft-delete for permanent deletion | MEDIUM | Page and sheet confirmation copy names `Desativar participante` and preserved inscription history. |
| Cached list continues showing an inactivated participant | MEDIUM | Delete mutation invalidates list queries and page filters only render active list response from backend. |
| Offline search regresses by fetching on each keypress | MEDIUM | Search input remains local state and filters `participantesQuery.data?.data` with `useMemo`; no `q` query key update during typing. |
| Role-disabled UI hides backend errors | MEDIUM | Page disables unavailable controls but still handles `ApiError` from mutation failures in the sheet. |
</threat_model>
