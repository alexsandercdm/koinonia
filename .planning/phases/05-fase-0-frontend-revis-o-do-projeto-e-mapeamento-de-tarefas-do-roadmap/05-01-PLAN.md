## Tarefas

1. **InscricoesPage** — página completa de listagem de inscrições por evento
   - Seletor de evento (via GET /api/v1/eventos)
   - Listagem de inscrições (via GET /api/v1/eventos/:id/inscricoes)
   - Filtro por status (PENDENTE, PAGO_PARCIAL, PAGO_TOTAL, LISTA_ESPERA, CANCELADA)
   - Hook use-inscricoes.ts com apiFetch

2. **Dashboard** — ativar botão de Inscrições e Participantes com navegação real

3. **App.tsx** — adicionar rota /inscricoes protegida

4. **Revisão** — confirmar alinhamento de AcomodacoesPage com schemas atuais

## Decisões de design

- Listagem por evento (único endpoint disponível: findByEventoId)
- Sem componentes badge/select/table no ui/ — usar HTML semântico com Tailwind
- apiFetch para todas as chamadas (gerencia auth automaticamente)
