**Edit 2 — `packages/shared/src/index.ts` lines 82-83:**

Change `z.number()` to `z.coerce.number()` for both fields:

Change:
```typescript
valor_total: z.number().min(0),
valor_pago: z.number().min(0),
```

To:
```typescript
valor_total: z.coerce.number().min(0),
valor_pago:  z.coerce.number().min(0),
```

Rationale: node-postgres returns `numeric(10,2)` columns as JavaScript strings by default. `z.number()` fails on strings; `z.coerce.number()` converts `"150.00"` → `150` correctly. The `.min(0)` constraint is preserved unchanged. No other fields in `InscricaoSchema` need this change.
