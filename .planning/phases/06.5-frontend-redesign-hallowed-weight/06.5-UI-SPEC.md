# Phase 06.5 — UI Design Contract

> Visual and interaction contract for the Hallowed Weight redesign. **Replaces** the Stitch (dark/purple/amber) design system shipped in Phase 5. Source of truth: `doc/Koinonia-redesign/`. Locked decisions sourced from `doc/Koinonia-redesign/HANDOFF.md` (D1 + tokens) and `UI-REVIEW.md` (audit findings). Scope per ROADMAP UX-01..UX-07.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (existing — keep Sheet/Dialog/Button primitives, remap palette via CSS vars) |
| Preset | custom — Tailwind tokens defined in `apps/web/tailwind.config.js` + `apps/web/src/index.css` (per Decision D1, HANDOFF.md) |
| Component library | radix (via shadcn/ui — Sheet, Dialog, Tabs, etc.) wrapped by 12 Hallowed Weight primitives |
| Icon library | **Material Symbols Outlined** (Google Fonts) via `<Icon name size fill />` primitive. **Banned:** `lucide-react` (must be removed during this phase). |
| Font | **DM Sans** (300/400/500/600/700 + 400 italic) loaded via Google Fonts in `apps/web/index.html`. Fallback stack: `system-ui, -apple-system, sans-serif`. **Banned:** `font-black` (900). |

### Architecture decision (D1 — locked)

Port the redesign's `C` token object into Tailwind theme extensions + CSS custom properties. Do not adopt inline-style approach. Do not introduce CSS Modules. Maintain shadcn/ui primitives (`Sheet`, `Dialog`) as base and remap palette via `index.css` HSL variables. Translate semantic tokens to shadcn variable names where possible (e.g., `--background → bg`, `--foreground → text`, `--primary → text`, `--accent → gold`).

### Accent reserved for (gold appears ≤5× per screen — audit threshold)

Gold (`#C4923A`) is the **single decorative accent**. It must appear **only** in these contexts:

1. **Brand mark dash:** 40×2px gold rule above login display heading.
2. **EventPill calendar icon** + **active nav indicator** in sidebar (gold sliver on left edge when active).
3. **Active event status stripe:** 3-4px left border on the dashboard EventBanner card and on the active EventSelector card.
4. **Inline editorial CTAs:** "Esqueceu a senha?", "Ver todas", "Ver inscrições →", "Solicitar conta", "Detalhar", "Ver ficha". These are text-only links with gold color, no underline.
5. **Status badges where status is `gold`:** Event status `ABERTO` only (per `EVENTO_STATUS` map).
6. **Progress bars representing financial / capacity goals** when fill is from goal-tracking (NOT generic progress).
7. **Focus ring** on inputs: `box-shadow: 0 0 0 3px gold-light` + border `gold-muted`.
8. **Icon tile backgrounds** for "Encontrista" papel chip and gold-themed KPIs (Inscrições KPI, Saldo líquido KPI). Limit: at most ONE gold KPI per dashboard view.
9. **Drawer "Novo evento" footer link** + **"Criar novo evento"** dashed button hover state on EventSelector.
10. **Active step underline** in multi-step drawer (current step = 2px gold border-bottom; completed steps = gold-muted).

**Banned uses for gold:**
- Primary CTA buttons (those use `text` / near-black).
- Generic hover backgrounds.
- Any decorative gradient.
- Headings (text-color).
- Icons in non-EventPill contexts (default icon color is `text-sec` or `text-ter`).
- More than ONE gold accent per row/grouping.

**Audit rule (for ui-checker):** Grep gold token (`text-gold`, `bg-gold`, `border-gold`, `gold-light`, `gold-muted`) per page component. If matches >5 in a single page file, flag as overuse and require justification.

### Destructive

Destructive actions use `danger` (`#9B3A2E`) on `danger-light` (`#FBECEC`) background with `#F0CACA` border. Button variant: `<Btn variant="danger">`. Reserved for: cancel inscription, delete event, delete participant, remove cama assignment.

## Interaction Contracts

### Motion / transitions

| Element | Property | Duration | Easing |
|---------|----------|----------|--------|
| Btn hover (bg/border/color) | all | `120ms` | `ease` |
| Card hover (border + shadow) | all | `150ms` | `ease` |
| Input focus (border + box-shadow) | border, box-shadow | `150ms` | `ease` |
| Drawer slide | transform | `250ms` | `cubic-bezier(0.4, 0, 0.2, 1)` |
| Drawer overlay fade | opacity | `200ms` | `ease` |
| EventPill dropdown (open/close) | all | `120ms` | `ease` |
| Progress bar fill | width | `400ms` | `ease` |
| `progress_activity` spinner | rotate | `800ms` | `linear infinite` |
| Live dot pulse | opacity scale | `1.5s` | `infinite` (custom keyframes) |

Reduced motion: respect `prefers-reduced-motion` — disable drawer slide transform (instant), disable live dot pulse, keep border/color transitions ≤120ms.

### Focus

- All interactive elements MUST have a visible focus ring.
- Inputs/Select/Textarea: `box-shadow: 0 0 0 3px gold-light` + `border: 1px solid gold-muted` on focus.
- Buttons: 2px gold-muted outline offset 2px (Tailwind `focus-visible:ring-2 focus-visible:ring-gold-muted focus-visible:ring-offset-2`).
- No `outline: none` without replacement.

### Hover

- Cards (only when clickable): border `border` → `border-strong`, shadow `0 1px 3px rgba(0,0,0,0.04)` → `0 2px 12px rgba(0,0,0,0.07)`.
- Table rows: bg `transparent` → `surface-raised` (#FDFCFA).
- Sidebar nav inactive: bg `transparent` → `surface-raised`.
- Sidebar nav active: bg `gold-light`, color `gold`, 3px left border `gold`.
- Btn primary: bg `text` (#1A1612) → `#2E2820`.
- Btn gold: bg `gold` → `#A87B2F`.
- Banido: `transform: scale()` em hover, `shadow-amber-accent/20`.

### Keyboard

- Drawer: `Esc` closes; focus traps within drawer when open; restore focus to trigger on close.
