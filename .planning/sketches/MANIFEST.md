# Sketch Manifest

## Design Direction

The redesign direction is Hallowed Weight: warm-light operational UI, restrained gold emphasis, clear cards, precise spacing, and mobile-first field usability. The latest design files are treated as high-fidelity references, so sketches should be used only where implementation choices remain uncertain.
