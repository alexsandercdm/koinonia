# HolyHouse Harness

Use this repository as a runtime-agnostic governance layer for AI-assisted development.

## Loop

1. Read `.holyhouse/STATE.md`, `.holyhouse/MEMORY.md`, and `.holyhouse/DECISIONS.md`.
2. Clarify the goal and constraints.
3. Plan with project context before changing code.
4. Execute with discipline: small steps, tests, verification, and rollback awareness.
5. Update memory and documentation before ending work.

## Rule

No agent may treat the current chat or a provider-specific runtime as the only source of truth. Local HolyHouse files are the governance record.
