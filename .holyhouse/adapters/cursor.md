# Cursor Adapter

HolyHouse Harness does not depend on Cursor. This adapter is documentation only.

## Guidance

- Use HolyHouse rules as human governance around Cursor agent activity.
- Keep HolyHouse as the human governance, memory, and quality layer.
- Run `holyhouse-harness gate` before accepting important changes.
- Run `holyhouse-harness memory` when the project learns something durable.
- Run `holyhouse-harness forensics` when state, intent, or repeated errors drift.
