# HolyHouse Methodology

HolyHouse Harness is the upper governance layer for AI-assisted development. It tells every agent how the project thinks, remembers, plans, executes, and proves quality.

## Operating Model

- Harness Engineering defines the project control plane.
- GSD captures context, plans work, validates assumptions, and maintains continuity.
- Superpowers guide disciplined execution through small, reversible, verified steps.
- Persistent memory is mandatory for decisions, state, risks, and lessons.
- Quality gates protect correctness, security, maintainability, and user value.
- Documentation is living project infrastructure, not after-the-fact reporting.
