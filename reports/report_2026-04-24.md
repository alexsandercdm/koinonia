## Issues por Tipo

### 🔐 Security (3 high, 1 medium)

#### [SEC-001] `apps/api/src/config/auth.ts:32` — `debug: true` em configuração de autenticação
- **Severidade:** 🟠 High
- **Problema:** Mode debug habilitado expõe stack traces, tokens e dados internos nos logs em produção.
- **Código:** `debug: true,`
- **Correção:** `debug: process.env.NODE_ENV !== 'production',`

#### [SEC-002] `apps/api/src/config/auth.ts:10` — `trustedOrigins` hardcoded com localhost
- **Severidade:** 🟠 High
- **Problema:** Origin hardcoded impede funcionamento em staging/produção sem alterar o código.
- **Código:** `trustedOrigins: ["http://localhost:3000"],`
- **Correção:** `trustedOrigins: [process.env.CORS_ORIGIN || 'http://localhost:3000'],`

#### [SEC-003] `apps/api/src/middleware/auth.ts:29` — Token parcial logado em console.error
- **Severidade:** 🟠 High
- **Problema:** Logar qualquer trecho de token em logs é um risco de segurança — logs podem ser indexados.
- **Código:** `` console.error(`...token: ${token.substring(0, 5)}...`) ``
- **Correção:** Remover o token do log. Usar apenas `console.error('AuthMiddleware - No session found')`

#### [SEC-005] `apps/api/src/app.ts:36` — JWT secret com fallback hardcoded
- **Severidade:** 🟠 High
- **Problema:** Se `JWT_SECRET` não estiver no ambiente, o app usa `'secret123'` como segredo — qualquer atacante pode forjar tokens JWT válidos.
- **Código:** `secret: env.JWT_SECRET || 'secret123',`
- **Correção:** Tornar `JWT_SECRET` obrigatório no schema Zod (`z.string().min(32)`) e remover o fallback.

#### [PERF-001] `apps/api/src/modules/inscricoes/usecases/GetInadimplentesUseCase.ts:29` — N+1 queries no banco
- **Severidade:** 🟠 High
- **Tipo:** Performance
- **Problema:** `getSumByInscricaoId` chamado individualmente para cada inscrição dentro de um loop — para 100 inscrições, gera 101 queries.
- **Código:** `for (const inscricao of inscricoes) { const totalPago = await this.pagamentoRepository.getSumByInscricaoId(inscricao.id) }`
- **Correção:** Usar uma única query com `GROUP BY`: `SELECT inscricao_id, SUM(valor) FROM pagamentos WHERE inscricao_id = ANY($ids) GROUP BY inscricao_id`

#### [SEC-004] `apps/api/src/config/auth.ts:34` — Verificação de e-mail desabilitada
- **Severidade:** 🟡 Medium
- **Problema:** `requireEmailVerification: false` permite cadastro com e-mails inválidos/inexistentes.
- **Código:** `requireEmailVerification: false,`
- **Correção:** Habilitar em produção ou documentar explicitamente por que está desabilitado.
